# Contributing to NexusLEO

NexusLEO development is bound by:

- `docs/doctrine/NexusLEO_Platform_Doctrine_v0.1.md`
- `docs/doctrine/NexusLEO_Doctrine_Code_Mapping_v0.1.md`

If a PR introduces behavior not mapped, it must be rejected or the doctrine/mapping must be version-bumped and updated.

Non-goals are hard constraints: no enforcement recommendations, no probable cause, no suspect ranking, no predictive policing.
